# Campus Resource Organizer

A Python command-line application designed to help students organize and search academic resources.

## Features
- Add study resources with titles and categories
- View all saved resources
- Search by title or category
- Validate required inputs

## Technologies
- Python 3

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run:

    python main.py

## Concepts Used
- Functions
- Lists and dictionaries
- Loops and conditional statements
- Input validation

## Current Limitations
Resources are stored in memory and disappear when the program exits.
